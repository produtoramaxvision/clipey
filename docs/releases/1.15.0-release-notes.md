# Clipey 1.15.0

**First public release.** Clipey is a free screen recorder and video editor for Windows, macOS
and Linux, built by [Produtora MaxVision](https://clipey.com.br).

---

## Highlights

- **Publish from the export dialog** to YouTube, Facebook Pages, Instagram Reels and TikTok,
  or schedule a post for later. The schedule is saved and survives restarts.
- **Subtitle files.** Save a `.srt` or `.vtt` next to an exported video, with times that follow
  your trims and speed changes. Import `.srt` and `.vtt` files onto the timeline too.
- **Import from a link.** Paste a public video link in the editor to bring the video into a project.
- **Auto Clip review.** Candidate clips are grouped by duration and show their scores.
- **More voices.** Gemini and Grok voices for generated speech, with a cost estimate before you generate.
- **Hardware acceleration choice.** Configure Auto, GPU or CPU rendering in the app menu and Recording HUD settings, with graceful software fallback and relaunch guards.
- **Custom cover picker.** Choose a custom cover image file for publishing and publish kits with path authorization.
- **Cursor motion presets** (Smooth, Balanced, Snappy, Precise) and a media card menu with rename,
  transcribe, find highlights, show in folder and remove with undo.
- **Draw on screen while recording** (Ctrl+Shift+D by default), also from the keyboard. Turn it off in the recording bar.
- **A first-run welcome** on Windows and Linux, a choice of where recordings are saved, MP4 export you can cancel,
  and an optional beta update channel in the tray menu.
- **An in-app MCP server** so AI agents can work on your projects. Edits by agents are a separate opt-in.

Available but **off by default** (turn them on in the app's settings):

- Keyboard shortcut overlay for Windows recordings. It shows shortcuts only; ordinary typing is never recorded.
- Gamepad capture with an on-screen overlay, for Windows recordings.
- Mouse click effects (ripple, rings, pulse) and focus effects (halo, spotlight) in the cursor panel.
- Face reframe, with a blurred background for other aspect ratios.

---

## Mobile companion

- **Mobile companion app:** Connect a phone or tablet to Clipey with pairing via QR code. The desktop host service is disabled by default and can be turned on in Settings. Available for Android via sideloaded APK and for iOS as an installed Progressive Web App (PWA) over Tailscale or local network (LAN) HTTPS.

### Windows: the SmartScreen warning

Windows SmartScreen warns the first time you run the installer. Choose **More info**, then
**Run anyway**. SmartScreen builds its reputation per file while a file is unsigned, so each new
version can show the warning again.

On Windows 11 with **Smart App Control** turned on, an unsigned installer can be blocked with no
"Run anyway" choice. Smart App Control can be switched off in Windows Security (**Settings → Privacy & security → Windows Security → App & browser control**); recent Windows updates allow it to be re-enabled without reinstalling Windows.

### macOS: opening an unsigned app

1. Open the `.dmg` and drag Clipey into **Applications**. Run Clipey from Applications, not from
   the disk image or from Downloads.

**On macOS 15 Sequoia:**
Apple removed the Control-click "Open" bypass in macOS 15. Attempting to Control-click gives no "Open" option and displays only a blocking message. Follow these steps:
1. Open Clipey from Applications. macOS shows a prompt that the app cannot be opened because Apple cannot check it for malicious software. Choose **Done** (or **OK**); do not choose **Move to Trash**.
2. Open **System Settings**, then **Privacy & Security**, and scroll to **Security**. Next to the message stating Clipey was blocked, click **Open Anyway**.
3. Authenticate with Touch ID or your login password, then click **Open**.

The **Open Anyway** button appears for about an hour after your attempt to open the app. If it is gone, open Clipey once more and check again. This is the procedure Apple describes in [Open a Mac app from an unknown developer](https://support.apple.com/guide/mac-help/mh40616/mac).

**On macOS 14 Sonoma (and earlier):**
You can use the standard Gatekeeper bypass:
1. In Finder, Control-click (or right-click) **Clipey** in Applications.
2. Choose **Open** from the shortcut menu.
3. Click **Open** in the confirmation dialog.

**Terminal alternative (all macOS versions):**
If the Open Anyway button does not appear or you prefer the command line, remove the quarantine attribute in Terminal and launch Clipey:

```bash
xattr -dr com.apple.quarantine /Applications/Clipey.app
```

The first time you record, macOS asks for **Screen Recording** permission, and for Microphone and
Camera if you use them. Allow them in **System Settings → Privacy & Security**, then reopen Clipey.

### Verify the download

Each release publishes checksum metadata files: `latest.yml` (Windows and general) and `latest-linux.yml` (Linux). Open the file in a text editor. Under `files:`, locate the entry for your downloaded file and copy the `sha512:` value.

#### Windows (PowerShell)

Run the following in PowerShell, replacing the path and expected base64 hash:

```powershell
$file = "$env:USERPROFILE\Downloads\Clipey.Setup.1.15.0-x64.exe"
$expected = "PASTE-THE-sha512-VALUE-FROM-latest.yml-HERE"

$hex = (Get-FileHash $file -Algorithm SHA512).Hash
$bytes = New-Object byte[] ([int]($hex.Length / 2))
for ($i = 0; $i -lt $bytes.Length; $i++) {
    $bytes[$i] = [Convert]::ToByte($hex.Substring(2 * $i, 2), 16)
}
$actual = [Convert]::ToBase64String($bytes)

if ($actual -eq $expected) { "OK: the file matches latest.yml" } else { "MISMATCH: do not install this file" }
```

#### Linux (bash)

Run the following in terminal to verify your Linux download against `latest-linux.yml`:

```bash
file="Clipey-Linux-1.15.0.AppImage"
expected="PASTE-THE-sha512-VALUE-FROM-latest-linux.yml-HERE"

actual=$(sha512sum "$file" | cut -d " " -f 1 | xxd -r -p | base64)

if [ "$actual" = "$expected" ]; then
    echo "OK: the file matches latest-linux.yml"
else
    echo "MISMATCH: do not install this file"
fi
```

## System requirements

- Windows 10 (64-bit) or later.
- macOS 13 (Ventura) or later, on Apple Silicon or Intel.
- A 64-bit Linux desktop with PipeWire and `xdg-desktop-portal`; the portal asks which screen or window to record.
- Local Whisper transcription downloads a speech model of about 264 MB on first use. On Linux, the local Whisper helper uses Vulkan GPU acceleration when supported hardware and drivers (such as Mesa Vulkan drivers) are installed, automatically falling back to CPU execution otherwise.

---

## Security

- Only Clipey's own windows can send commands to the app's main process, and every window is sandboxed.
- A strict content security policy limits what the app's pages can load or run.
- Local media is served only for files you opened or recorded.
- Clipey's windows cannot be navigated to outside pages. Camera, microphone and screen-capture permissions are given only to Clipey's own windows.
- Account tokens and API keys are kept in the app's encrypted secrets store. Disconnecting a publishing account revokes its token with the provider, and retries if that fails.
- The installed app refuses to load modified application code, and updates are checked against the checksum published with the release.
- Link import refuses addresses on your own computer or network.
- Diagnostic files remove API keys, access tokens and your user folder path.

---

## Known limitations

- The Windows installer and the macOS app are not code-signed (see above). Code signing needs
  paid accounts with Microsoft and Apple; the plan is in `docs/releases/code-signing-roadmap.md`.
- **On macOS, Clipey cannot update itself in place while it is unsigned.** When a new version exists, Clipey offers **Download the new .dmg**. It does this after a daily check while the app stays open, or any time you choose **Check for Updates** in the menu bar icon's menu. Open the downloaded file and replace Clipey in Applications; your projects and settings are kept.
- **Linux packages are unsigned.** You can verify the integrity of your download by checking the SHA-512 checksum published in `latest-linux.yml`.
- **Linux speech recognition:** The local Whisper speech recognition helper uses Vulkan acceleration on Linux when compatible hardware/drivers are available, falling back to CPU processing otherwise.
- The TikTok, Meta and Google app reviews are not finished, so connecting an account can be limited or show an unverified-app notice.
- Disconnecting TikTok may not revoke the token on the server yet, because the sign-in service route for it is not deployed. Clipey warns you and retries.
- Speech recognition models (~264 MB) are downloaded on first use from Hugging Face, while word-timing CTC aligners are fetched from Clipey release assets.

The complete list of changes is in `CHANGELOG.md` in the repository.

## Destaques

- **Publique pelo diálogo de exportação** no YouTube, Facebook Pages, Instagram Reels e TikTok,
  ou agende uma publicação para depois. O agendamento é salvo e continua valendo após reiniciar o app.
- **Arquivos de legenda.** Salve um `.srt` ou `.vtt` ao lado do vídeo exportado, com tempos que
  acompanham seus cortes e mudanças de velocidade. Importe também arquivos `.srt` e `.vtt` para a linha do tempo.
- **Importação por link.** Cole o link de um vídeo público no editor para trazê-lo para um projeto.
- **Revisão do Auto Clip.** Os trechos candidatos são agrupados por duração e mostram suas pontuações.
- **Mais vozes.** Vozes Gemini e Grok para a fala gerada, com estimativa de custo antes de gerar.
- **Escolha de aceleração de hardware.** Configure a aceleração (Automática, GPU ou CPU) no menu do app e na barra de gravação (HUD), com transição suave para renderização por software e proteção durante gravações ou exportações ativas.
- **Seletor de capa personalizada.** Escolha um arquivo de imagem próprio para a capa do vídeo na publicação e nos kits de publicação com autorização de caminho segura.
- **Predefinições de movimento do cursor** (Suave, Equilibrado, Ágil, Preciso) e um menu nos cartões de mídia
  com renomear, transcrever, encontrar destaques, mostrar na pasta e remover com desfazer.
- **Desenhe na tela durante a gravação** (Ctrl+Shift+D por padrão), também pelo teclado. Desative na barra de gravação.
- **Boas-vindas na primeira execução** no Windows e no Linux, escolha da pasta das gravações, exportação MP4 que pode ser
  cancelada e um canal opcional de versões beta no menu da bandeja.
- **Um servidor MCP no app** para que agentes de IA trabalhem nos seus projetos. As edições feitas por agentes são uma permissão à parte.

Disponíveis, mas **desativados por padrão** (ative nas configurações do app):

- Sobreposição de atalhos de teclado nas gravações no Windows. Mostra apenas atalhos; a digitação comum nunca é registrada.
- Captura de gamepad com sobreposição na tela, nas gravações no Windows.
- Efeitos de clique do mouse (ondulação, anéis, pulso) e de foco (halo, holofote) no painel do cursor.
- Reenquadramento de rosto, com fundo desfocado para outras proporções de tela.

### macOS: abrir um app sem assinatura

1. Abra o `.dmg` e arraste o Clipey para **Aplicativos**. Execute o Clipey a partir de Aplicativos,
   não da imagem de disco nem da pasta Downloads.
2. Abra o Clipey pela pasta Aplicativos. O macOS mostra uma mensagem dizendo que não consegue
   verificar se o app contém software malicioso. Escolha **Concluído** (ou **OK**); não escolha
   **Mover para o Lixo**.
3. Abra os **Ajustes do Sistema**, depois **Privacidade e Segurança**, e role até **Segurança**.
   Ao lado da mensagem sobre o Clipey, escolha **Abrir Mesmo Assim**.
4. Digite sua senha de início de sessão e clique em **OK**.

O botão **Abrir Mesmo Assim** aparece por cerca de uma hora depois da sua primeira tentativa de
abrir o app. Se ele sumiu, abra o Clipey mais uma vez e olhe de novo. Este é o procedimento que a
Apple descreve em [Abrir um app do Mac de um desenvolvedor desconhecido](https://support.apple.com/pt-br/guide/mac-help/mh40616/mac).

Se o botão nunca aparecer, remova a marca de quarentena em uma janela do Terminal e abra o Clipey de novo:

```bash

```

Na primeira gravação, o macOS pede a permissão de **Gravação de Tela** e, se você usar, a de
Microfone e a de Câmera. Permita em **Ajustes do Sistema → Privacidade e Segurança** e abra o Clipey de novo.

## Segurança

- Somente as janelas do próprio Clipey podem enviar comandos ao processo principal do app, e todas as janelas rodam em modo isolado (sandbox).
- Uma política de segurança de conteúdo rígida limita o que as páginas do app podem carregar ou executar.
- A mídia local é servida apenas para arquivos que você abriu ou gravou.
- As janelas do Clipey não navegam para páginas externas. As permissões de câmera, microfone e captura de tela são concedidas apenas às janelas do próprio Clipey.
- Tokens de contas e chaves de API ficam no cofre criptografado do app. Ao desconectar uma conta de publicação, o token é revogado no provedor, com nova tentativa se falhar.
- O app instalado se recusa a carregar código de aplicativo modificado, e as atualizações são conferidas com o checksum publicado na release.
- A importação por link recusa endereços do seu próprio computador ou da sua rede.
- Os arquivos de diagnóstico removem chaves de API, tokens de acesso e o caminho da sua pasta de usuário.

## Limitações conhecidas

- O instalador do Windows e o app do macOS não têm assinatura de código (veja acima). A assinatura
  exige contas pagas na Microsoft e na Apple; o plano está em `docs/releases/code-signing-roadmap.md`.
- **No macOS, o Clipey não consegue se atualizar sozinho enquanto não tiver assinatura de código.** Quando houver uma nova versão, o Clipey oferece **Baixar o novo .dmg**: após uma verificação diária enquanto o app fica aberto, ou quando você escolher **Verificar atualizações** no menu do ícone da barra de menus. Abra o arquivo baixado e substitua o Clipey em Aplicativos; seus projetos e configurações são mantidos.
- **Os pacotes para Linux não têm assinatura de código.** Você pode conferir a integridade do arquivo baixado comparando o checksum SHA-512 publicado em `latest-linux.yml`.
- **Reconhecimento de fala no Linux:** O módulo local do Whisper utiliza aceleração Vulkan no Linux caso haja drivers e hardware compatíveis; caso contrário, executa na CPU.
- As revisões de aplicativo do TikTok, da Meta e do Google ainda não terminaram; por isso, conectar uma conta pode ter limitações ou exibir um aviso de aplicativo não verificado.
- Ao desconectar o TikTok, o token pode ainda não ser revogado no servidor, porque a rota do serviço de login para isso ainda não foi publicada. O Clipey avisa você e tenta de novo.
- Os modelos de reconhecimento de fala (~264 MB) são obtidos no primeiro uso do Hugging Face, enquanto os alinhadores CTC de sincronização de palavras são baixados sob demanda dos arquivos de release do Clipey.

A lista completa de mudanças está em `CHANGELOG.md`, no repositório.
