# Perguntas frequentes

**O Windows diz "editor desconhecido". É seguro?**
Os instaladores ainda não são assinados. Baixe apenas pela página de Releases deste repositório.

**Onde ficam minhas gravações?**
Em `%APPDATA%\Clipey\recordings`. Projetos em `%APPDATA%\Clipey\projects`.

**Projetos do OpenScreen abrem no Clipey?**
Sim, arquivos `.openscreen` abrem normalmente. Projetos novos são salvos como `.clipey`.

**Como fechar o Clipey de verdade?**
Ícone na bandeja → **Sair**. Para o X encerrar o app, desmarque "Continuar na bandeja ao fechar" no menu da bandeja.
