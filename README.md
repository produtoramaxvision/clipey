## Download

Baixe o instalador mais recente em [Releases](../../releases). O Clipey verifica atualizações a partir daqui.

> Os instaladores ainda não são assinados digitalmente. O Windows SmartScreen pode exibir "editor desconhecido" na primeira execução.

## O que o Clipey faz

- Gravação de tela, janela, webcam, microfone e áudio do sistema.
- Editor com linha do tempo, zooms automáticos a partir dos cliques, câmera que segue o cursor e formatos 16:9, 9:16 ou automático.
- Transcrição e legendas (no computador ou em servidor próprio) e edição por texto.
- Assistente de IA para editar com comandos em linguagem natural.
- Exportação em MP4 (H.264) e GIF.
- Integração com agentes de IA via MCP (Model Context Protocol).

Em desenvolvimento (ainda não disponível para uso geral): publicação direta no YouTube, Facebook, Instagram e TikTok; dublagem com clonagem de voz; clipes automáticos para redes sociais.
